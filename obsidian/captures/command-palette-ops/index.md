## Layout

화면 중앙 팔레트: 검색 인풋, 최근/추천 그룹, 키보드 힌트. 배경 앱은 흐림 처리.

## Color

딥 셸 위 밝은 패널. 선택 행만 약한 틴트.

## Typography

명령어는 짧고, 단축키는 우측 정렬 캡션. Typeface: 미확정.

## Interaction

사용자 확인 필요 — 키보드 내비와 실행 피드백은 보이지 않음.
